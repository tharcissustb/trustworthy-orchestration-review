# Evidence-package freeze checklist

The following checks define the public evidence-package freeze. Manuscript
compilation and journal-submission approval are managed separately.

- [x] Every full-text report has one mutually exclusive status: included,
  excluded with one primary reason, or not retrieved.
- [x] Every analytical study has a persistent identifier or stable URL.
- [x] Publication dates satisfy the review window through 30 April 2026.
- [x] Duplicate and superseded reports are reconciled.
- [x] Quality-appraisal fields are complete for all 120 analytical studies.
- [x] Boundary, mechanism, evidence-type, and claim-status codes use values
  defined in the codebook.
- [x] Reliability reporting separates initial decisions from consensus
  adjudication.
- [x] Dashboard, PRISMA flow, included-study register, evidence map, and quality
  appraisal use identical frozen counts and study keys.
- [x] Screening and computational-validation checks run without publisher PDFs.
- [x] The numbered release manifest records file sizes and SHA-256 hashes.
